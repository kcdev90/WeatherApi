# Weather API

[![Kotlin1_9](https://img.shields.io/badge/Kotlin-1.9-ff69b4)]() [![MVVM](https://img.shields.io/badge/MVVM-red)](https://developer.android.com/topic/libraries/architecture/viewmodel) [![JetpackCompose](https://img.shields.io/badge/Jetpack_Compose-2025.2-lightgray)](https://developer.android.com/jetpack/compose) [![ComposeNavigation](https://img.shields.io/badge/Compose_Navigation-2.8-green)]() [![Retrofit](https://img.shields.io/badge/Retrofit-2.9-blue)]() [![KotlinXSerialization](https://img.shields.io/badge/KotlinX_Serialization-1.6-purple)]() [![MockK](https://img.shields.io/badge/MockK-1.13-yellow)]()

Simple demo project that gets weather data from an external API and displays it in the UI

**Features**
----------

- Retrieve data from remote source ✔️
- Display data in Compose UI ✔️
- Details screen for most in-depth info on particular city ✔️
- Navigate between screens with Compose Navigation ✔️
- Live updates with Kotlin Flows ✔️
- Clean Architecture ✔️
- Supports both Portrait and Landscape orientation ✔️
- Assured code robustness with MockK unit tests ✔️
